## Question
In second-order arithmetic, working over the subsystem $\mathsf{ATR}_0$, call a set $A$ Lebesgue-regular if its outer Lebesgue measure $\lambda^*(A)=\inf\{\lambda(B): A\subset B\text{ and }B\text{ is open}\}$ equals its inner Lebesgue measure $\lambda_*(A)=\sup\{\lambda(B): B\subset A\text{ and }B\text{ is compact}\}$. Which of the following statements is equivalent to the assertion that every analytic set $A \subseteq [0,1]$ is Lebesgue-regular?

## Choices
A. Every analytic set $A\subseteq[0,1]$ is Lebesgue-regular, and there exist an open set $U\supseteq A$ and a compact set $K\subseteq A$ such that $\lambda(U)=\lambda(K)$.
B. For every analytic set $A\subseteq[0,1]$, whenever both $\lambda^*(A)$ and $\lambda_*(A)$ exist, one has $\lambda_*(A)\leq \lambda^*(A)$.
C. $\boldsymbol\Sigma^1_2$-Induction for $\mathbb{N}$.
D. $\boldsymbol\Sigma^1_1$-Induction for $\mathbb{N}$.
E. $\boldsymbol\Sigma^1_1$-Separation for subsets of $\mathbb{N}$.
