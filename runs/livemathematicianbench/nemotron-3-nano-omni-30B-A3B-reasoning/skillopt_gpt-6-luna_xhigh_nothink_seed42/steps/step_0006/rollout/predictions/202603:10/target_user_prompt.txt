## Question
Let $K$ be a totally real number field, let $\mathcal O=\mathcal O_K$ be its ring of integers, and let $n>2$ be an integer. Recall that a root lattice over $\mathcal O$ is a nonzero finitely generated free $\mathcal O$-module $L$ equipped with a nondegenerate symmetric bilinear form $L\times L\to\mathcal O$ that is totally positive definite and is generated by its roots $\Phi(L)=\{x\in L\mid x\cdot x=2\}$. Fix an irreducible root-system type $X_n$ of rank $n$, and write $c(X_n)$ for the scalar invariant attached to that type. What is the strongest correct statement about the existence of an irreducible root lattice over $\mathcal O$ of type $X_n$ under these assumptions?

## Choices
A. There exists an irreducible root lattice over $\mathcal O$ of type $X_n$ if and only if $c(X_n)\in K$, and the same equivalence remains valid without change for rank $n=2$ as well.
B. If $c(X_n)\in K$, then one can guarantee an irreducible root lattice of type $X_n$ only after passing to the ring of integers of some finite totally real extension of $K$; membership of $c(X_n)$ in $K$ alone does not ensure existence over $\mathcal O$ itself.
C. There exists an irreducible root lattice over $\mathcal O$ of type $X_n$ if and only if $c(X_n)\in \mathcal O$.
D. There exists an irreducible root lattice over $\mathcal O$ of type $X_n$ if and only if $c(X_n)\in K$.
E. If there exists an irreducible root lattice over $\mathcal O$ of type $X_n$, then necessarily $c(X_n)\in K$.
