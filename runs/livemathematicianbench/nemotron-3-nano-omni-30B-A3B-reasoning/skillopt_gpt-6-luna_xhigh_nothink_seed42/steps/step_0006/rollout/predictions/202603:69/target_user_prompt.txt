## Question
Consider the standard Bruin–Troubetzkoy family of interval translation mappings (ITMs). Restrict to the set of parameter values for which the associated ITM is of infinite type; here, “almost every” on this set refers to the natural probability measure supported on this zero-Lebesgue-measure subset. Which strongest conclusion holds for almost every such parameter value?

## Choices
A. For almost every parameter in the Bruin–Troubetzkoy family that defines an ITM of infinite type (with respect to the natural probability measure on the infinite-type locus), the resulting interval translation mapping is uniquely ergodic but not weakly mixing.
B. For almost every parameter in the Bruin–Troubetzkoy family that defines an ITM of infinite type (with respect to the natural probability measure on the infinite-type locus), the resulting interval translation mapping is weakly mixing.
C. There exists a full-measure subset of the Bruin–Troubetzkoy infinite-type locus such that every parameter in that subset defines an interval translation mapping that is uniquely ergodic and strongly mixing.
D. For almost every parameter in the Bruin–Troubetzkoy family that defines an ITM of infinite type (with respect to the natural probability measure on the infinite-type locus), the resulting interval translation mapping is strongly mixing.
E. For almost every parameter in the Bruin–Troubetzkoy family that defines an ITM of infinite type (with respect to the natural probability measure on the infinite-type locus), the resulting interval translation mapping is ergodic.
