## Question
Let $I$ be a stable roommates (SR) instance on $2n$ agents, and let $k$ denote the minimum crossing distance of $I$ (the paper’s structural-distance parameter measuring how far $I$ is from a stable marriage instance). Which of the following is the strongest asymptotic running-time guarantee for computing an optimal stable matching for $I$ as a function of $n$ and $k$?

## Choices
A. An optimal stable matching for $I$ can be found in time $2^{O(k\log n)} n^{O(1)}$; equivalently, in time $n^{O(k)}$, so the result gives only an XP guarantee in the parameter $k$, not an FPT one.
B. For every fixed value of $k$, an optimal stable matching for $I$ can be computed in polynomial time in $n$.
C. The theorem yields polynomial-time solvability for each fixed $k$, but only in a non-uniform sense: it does not provide a single bound of the form $f(k) n^{O(1)}$ that works uniformly over all values of $k$.
D. An optimal stable matching for $I$ can be found in time $n^{O(k)}$; since the exponent of $n$ depends only on $k$, this already shows that the problem is fixed-parameter tractable with respect to $k$.
E. An optimal stable matching for $I$ can be found in time $2^{O(k)} n^{O(1)}$, so the optimal stable matching problem is fixed-parameter tractable when parameterized by the minimum crossing distance $k$.
