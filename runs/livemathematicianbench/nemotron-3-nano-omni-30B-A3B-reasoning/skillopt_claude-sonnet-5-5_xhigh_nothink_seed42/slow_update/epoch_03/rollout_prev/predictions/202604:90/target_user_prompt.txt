## Question
Let \(U\) denote the unknot, and let \(\rho_p(K)\) denote the scale-invariant \(p\)-density associated to a knot type \(K\) in \(\mathbb{R}^3\), for each parameter \(p\in(-1,\infty]\). What is the strongest statement that holds for every knot type \(K\) and every \(p\in(-1,\infty]\)?

## Choices
A. For every \(p\in(-1,\infty]\setminus\{0\}\) and every knot type \(K\), one has \(\rho_p(K)\le \rho_p(U)\), whereas at \(p=0\) no universal comparison with the unknot holds.
B. For every \(p\in(-1,\infty]\) and every nontrivial knot type \(K\), one has \(\rho_p(K)<\rho_p(U)\).
C. For every \(p\in(-1,2]\cup\{\infty\}\) and every knot type \(K\), one has \(\rho_p(K)\le \rho_p(U)\).
D. For every \(p\in(-1,2]\cup\{\infty\}\) and every knot type \(K\), one has \(\rho_p(K)\le \rho_p(U)\), but for some finite \(p>2\) there exists a knot type \(K\) with \(\rho_p(K)>\rho_p(U)\).
E. For every \(p\in(-1,\infty]\) and every knot type \(K\), one has \(\rho_p(K)\le \rho_p(U)\).
