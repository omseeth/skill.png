### Election2020 Smartable: GetFAQsByTopic
Provider: Election2020 Smartable — The Election API offers the 2020 U.S. election news, events, important people, FAQs, and other information. The data is tagged with democratic voice and republican voice, so it's up to the user to decide which opinion to follow.

- topic (string)
- page (NUMBER)

### Coronavirus Smartable: GetStats
Provider: Coronavirus Smartable — The coronavirus Stats and News API offers the latest and historic COVID-19 stats and news information per country or state.
API: GetStats
Description: Retrieves the latest and historic coronavirus statistics, including confirmed cases, deaths, and recovered cases, for global or specific country/state regions. This endpoint is part of the Coronavirus Stats and News API, which provides comprehensive COVID-19 data and updates, drawing from real-time databases and historical records to support informed decision-making and situational awareness.
Required parameters:
- location (string): ISO 3166-2 location code. For example, use "FR" for coronavirus stats in France; use "US" for coronavirus stats in US; use "US-CA" for coronavirus stats in the US California state. Use "global" to retrieve global stats.
Optional parameters: none
