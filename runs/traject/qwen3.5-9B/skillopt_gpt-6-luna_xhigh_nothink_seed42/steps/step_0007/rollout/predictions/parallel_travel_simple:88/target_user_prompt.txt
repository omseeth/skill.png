## Tools
### Flightera Flight Data: flightSearch
Provider: Flightera Flight Data — Flight status, on-time performance and statistics by Flightera
API: flightSearch
Description: Retrieves a list of flights for a specific flight number, with optional date filters to narrow results, ordered by departure date ascending, and includes the next departure time for pagination. This endpoint is part of Flightera's service, which provides flight status, on-time performance, and statistics. It leverages the parent tool's data to ensure accurate flight information retrieval, enforcing subscription-level date range restrictions to deliver reliable results.
Required parameters:
- flnr (STRING): The flight number to request
Optional parameters:
- dtFrom (STRING): The minimum date to request
- dtTo (STRING): The maximum date to request
