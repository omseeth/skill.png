### CheapShark - Game Deals: List of Deals
Provider: CheapShark - Game Deals — CheapShark is a price comparison website for digital PC Games. We keep track of prices across multiple stores including Steam, GreenManGaming, Fanatical, and many others.
API: List of Deals
Description: Retrieves a paged list of game deals with optional filtering parameters, allowing users to search across price, store, game title, and other criteria. This endpoint leverages CheapShark's price comparison platform, which tracks digital PC game prices across stores like Steam, GreenManGaming, and Fanatical, providing normalized deal ratings on a 0-10 scale to help users identify optimal purchases. The returned deal objects include encoded dealIDs for linking to the redirect page (https://www.cheapshark.com/redirect?dealID={id}), though this page is intended for end-user navigation rather than automated integration.
Required parameters: none
Optional parameters:
- lowerPrice (NUMBER): Default `0` Only returns deals with a price *greater than* this value
- steamRating (NUMBER): Minimum Steam reviews rating for a game
- title (STRING): Looks for the string contained anywhere in the game name
- steamAppID (ARRAY): Look for deals on specific games, comma separated list of Steam App ID
- desc (BOOLEAN): Default `0` Determines sort direction
- output (STRING): Option to output deals in `RSS` format (overrides page number/size to `0`/`100`)
- steamworks (BOOLEAN): Default `0` Flag to include only deals that redeem on Steam (best guess, depends on store support)
- sortBy (STRING): Criteria to sort the list by, possible values - - Deal Rating - Title - Savings - Price - Metacritic - Reviews - Release - Store - recent
- AAA (BOOLEAN): Default `0` Flag to include only deals with retail price > `$29`
- pageSize (NUMBER): The size of pages returned, default and maximum value is `60`
- exact (BOOLEAN): Default `0` Flag to allow only exact string match for `title` parameter
- upperPrice (NUMBER): Only returns deals with a price* less than or equal to` this value (`50` acts the same as no limit)
- pageNumber (NUMBER): The requested page number, 0 indexed, default of `0`
- onSale (BOOLEAN): Default `0` Flag to include only games that are currently on sale
- metacritic (NUMBER): Minimum Metacritic rating for a game
- storeID (ARRAY): Comma separated list of store ID's to filter on, omit for deals from any store
