## Tools
### Genius - Song Lyrics: Referents
Provider: Genius - Song Lyrics — Genius - Song Lyrics, Artists, Albums, Knowledge & More API
API: Referents
Description: Retrieves referents (sections of content with annotations) by specifying either a song_id or web_page_id parameter, but not both. This endpoint uses Genius's extensive database of song lyrics, artists, albums, and knowledge to return sections of content that have annotations attached to them. Each referent is linked to either a song or web page and may contain multiple annotations. Results can be filtered by the document they're attached to or by the user who created the annotations, allowing you to access the rich contextual information and community knowledge that makes up Genius's collaborative annotation platform.
Required parameters: none
Optional parameters:
- song_id (STRING): ID of a song to get referents for
- page (NUMBER): Paginated offset, (e.g., per_page=5&page=3 returns songs 11–15)
- created_by_id (STRING): ID of a user to get referents for
- text_format (STRING): Format for text bodies related to the document. One or more of `dom`, `plain`, `markdown`, and `html`, separated by commas (defaults to html).
- per_page (NUMBER): Number of results to return per request
- web_page_id (STRING): ID of a web page to get referents for

### Shazam: songs/get-count
Provider: Shazam — Identify any song. Discover, artists, lyrics, videos & playlists to create a song detector site/application such as shazam.com
API: songs/get-count
Description: Retrieves the total number of times a specific song has been detected or Shazamed using the /songs/detect or /songs/v2/detect endpoint. This leverages Shazam's powerful music recognition technology that can identify virtually any song from its audio signature, providing access to the same song detection capabilities that power shazam.com. The data includes comprehensive detection statistics that can be integrated into music discovery applications, allowing developers to build features showing song popularity based on how often users around the world have identified tracks through the Shazam service.
Required parameters:
- key (STRING): The key field returned from .../songs/detect or .../search endpoint
Optional parameters: none
