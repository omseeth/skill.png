## Tools
### Spotify: Get artists
Provider: Spotify — Spotify Data API for Millions of songs & podcasts, artists, albums, playlists and more.
API: Get artists
Description: Retrieves information about one or more specific artists from Spotify's extensive music database. This endpoint taps into Spotify's comprehensive Data API, which provides access to millions of songs, podcasts, albums, and playlists, allowing you to obtain detailed artist profiles including popularity metrics, genres, images, and related content. Perfect for music discovery, analysis, or integration into applications that require rich artist metadata from one of the world's largest music streaming platforms.
Required parameters:
- ids (STRING): Artist IDs (you can use commas)
Optional parameters: none

### SoundCloud Scraper: Search for Playlists
Provider: SoundCloud Scraper — An all-in-one SoundCloud scraper/downloader. Scrapes albums, playlists, profiles. Downloads uncut high-quality audios and lyrics.
API: Search for Playlists
Description: Searches for SoundCloud playlists with optional filters and supports pagination scraping. This endpoint is part of an all-in-one SoundCloud scraper/downloader that allows comprehensive access to SoundCloud content, including the ability to scrape albums, playlists, and profiles, as well as download uncut high-quality audio files and lyrics.
Required parameters:
- term (STRING): Search term.
Optional parameters:
- offset (NUMBER): (**README**: [How to Use Endpoints with `offset`](https://rapidapi.com/DataFanatic/api/soundcloud-scraper/tutorials/how-to-use-endpoints-with-%60offset%60)) The number of items omitted before the results. Defaults to `0`.
- limit (NUMBER): The max number of items returned. Defaults to `50`.
- genreOrTag (STRING): Filters by genre or tag (e.g., `classical`).

### Shazam: songs/get-count
Provider: Shazam — Identify any song. Discover, artists, lyrics, videos & playlists to create a song detector site/application such as shazam.com
API: songs/get-count
Description: Retrieves the total number of times a specific song has been detected or Shazamed using the /songs/detect or /songs/v2/detect endpoint. This leverages Shazam's powerful music recognition technology that can identify virtually any song from its audio signature, providing access to the same song detection capabilities that power shazam.com. The data includes comprehensive detection statistics that can be integrated into music discovery applications, allowing developers to build features showing song popularity based on how often users around the world have identified tracks through the Shazam service.
Required parameters:
- key (STRING): The key field returned from .../songs/detect or .../search endpoint
Optional parameters: none
