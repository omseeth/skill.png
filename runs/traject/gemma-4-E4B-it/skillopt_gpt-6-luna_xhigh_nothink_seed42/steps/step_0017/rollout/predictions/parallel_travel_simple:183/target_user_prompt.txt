### Priceline com Provider: Hotel reviews
Provider: Priceline com Provider — priceline.com | Lets you search hotels, cars for rent, flights. **Support**: [tipsters@rapi.one](mailto:tipsters@rapi.one) / t.me/api_tipsters **Other travel api:** https://rapi.one

Description: Returns a list of reviews for travel services such as hotels, cars, and flights. This endpoint is part of the Priceline.com API, which enables users to search and book travel accommodations and rentals. It leverages a database of user-generated reviews to provide insights, helping travelers make informed decisions about their bookings.
Required parameters:
- hotel_id (STRING): The PPN Hotel ID identifying the desired property.
Optional parameters:
- languages (STRING): Limits the number of results from the response.
- order_by (STRING): CSV of sorting order metrics. Valid Options: creation_date, average_rating, or verified_guest followed by .asc or .desc.

- limit (NUMBER): Limits the number of results from the response.
- only_verified_guests (BOOLEAN): Set on to only include only reviews with verified_guests. A verified guest is a guest that has had a review verified by aaa. Valid Options: 0 = Off, 1 = On.

### Flightera Flight Data: airportFlights
Provider: Flightera Flight Data — Flight status, on-time performance and statistics by Flightera
API: airportFlights
Description: Retrieves a sorted list of flights for a specific airport, direction, and time, sorted ascending by scheduled departure time for departures and descending by scheduled arrival time for arrivals, with the next departure/arrival time provided for pagination. This endpoint is part of Flightera's service for flight status, on-time performance, and statistics, leveraging detailed flight data to provide actionable insights. The scheduled departure dates in local time can be used to query additional flight information via the /flight/info endpoint.
Required parameters:
- direction (STRING): Direction, one of "arrival", "departure"
- ident (STRING): Ident of the airport to request. Ident is the unique identifier as returned by /airport/search or /airport/info endpoints.
- time (STRING): Timestamp in UTC. If direction is "arrival", show flights with scheduled arrival time prior to this timestamp. If direction is "departure", show flights with scheduled departure time after this timestamp. Expected in any valid format, such as 2022-01-01T12:00:00.000Z. Maximum range of flights returned is 30 days.
Optional parameters:
- counterpart_ident (STRING): Ident of the counterpart airport (destination if direction=arrival, otherwise arrival). Used to query connections on a defined route. Ident is the unique identifier as returned by /airport/search or /airport/info endpoints.

## Query
I need to gather comprehensive travel information across multiple countries. First, I retrieved a complete list of countries from the Travelpayouts Data API to establish a geographic reference database. Then I focused on specific airline information by querying the Airport Guide's aviation database for airlines operating in Canada (CA), Portugal (PT), and Thailand (TH), which provided details including airline names, IATA/ICAO IDs, and contact information. I also checked current gasoline prices across Canada to understand fuel costs for road travel. Finally, I explored accommodation options through Priceline's API, downloading a comprehensive list of property types (limited to 100 entries) and available amenity filters (also limited to 100) to better understand lodging categories and available facilities for travelers.
