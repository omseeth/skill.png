## Tools
### meteostat: Monthly Station Data
Provider: meteostat — Historical Weather & Climate Data API
API: Monthly Station Data
Description: Retrieves historical monthly weather statistics for a specific station by aggregating data from multiple governmental interfaces. This is part of the Historical Weather & Climate Data API, which provides comprehensive historical weather and climate data to support analysis and decision-making, leveraging authoritative sources for accuracy and reliability.
Required parameters:
- station (STRING): The Meteostat weather station identifier.
- end (DATE (YYYY-MM-DD)): The end date of the period (YYYY-MM-DD).
- start (DATE (YYYY-MM-DD)): The start date of the period (YYYY-MM-DD).
Optional parameters:
- units (STRING): The unit system of the meteorological parameters. Default is metric.
- model (BOOLEAN): A boolean parameter which specifies whether missing data should be substituted with statistically optimized model data. Default is *true*.
- freq (STRING): The time frequency of the records. Can be used for custom aggregation. Default is *null*.

- type (STRING): type, Event type (list forthcoming)
- point (STRING): point, Point (latitude,longitude)
- state (STRING): State/marine code (list forthcoming)
- zone (STRING): zone, Zone Id (forecast or county, list forthcoming)
- urgency (STRING): urgency, Urgency (expected, immediate)
- region (STRING): region, Region code (list forthcoming)

### RapidWeather: Call 5 day / 3 hour forecast data - By geographic coordinates
Provider: RapidWeather — The proprietary convolutional neural network collects and processes wide range of data sources to cover any location and consider the local nuances of climate. We collect and process weather data from different sources such as global and local weather models, satellites, radars and vast network of weather stations. For each point on the globe, RapidWeather provides historical, current and forecasted weather data via light-speed APIs.
API: Call 5 day / 3 hour forecast data - By geographic coordinates
Description: Generates a 5-day weather forecast with 3-hour intervals based on geographic coordinates. This uses a proprietary convolutional neural network that integrates global and local weather models, satellite data, radar systems, and a network of weather stations to analyze climate nuances, delivering accurate historical, current, and forecasted weather data through high-speed APIs for precise meteorological insights.
Required parameters:
- lon (NUMBER): Geographical coordinates (latitude, longitude)
- lat (NUMBER): Geographical coordinates (latitude, longitude)
Optional parameters:
- units (STRING): Units of measurement. **standard**, **metric **and **imperial **units are available. If you do not use the **units **parameter, **standard **units will be applied by default.
- lang (STRING): You can use the **lang **parameter to get the output in your language.
- cnt (NUMBER): A number of timestamps, which will be returned in the API response.
