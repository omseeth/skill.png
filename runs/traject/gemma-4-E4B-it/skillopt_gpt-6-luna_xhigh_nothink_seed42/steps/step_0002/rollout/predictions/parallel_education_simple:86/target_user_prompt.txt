### TED Talks API: getTalks
Provider: TED Talks API — Get TED talks based on multiple different parameters and filtering options, from the speaker, topic, talk duration, and more.
API: getTalks
Description: Gets detailed information about specific TED talks based on provided parameters such as speaker name, topic, or duration. This endpoint leverages a comprehensive database of TED talks, allowing you to filter and retrieve targeted content from the vast collection of presentations. The service enables precise searching across multiple dimensions including speakers, subject matter, talk length, and additional filtering options, making it easy to find exactly the inspirational or educational content you're looking for.
Required parameters: none
Optional parameters:
- id (NUMBER): ID of a desired specific talk
- audio_lang (STRING): Return talks which their audio language is the provided language, the provided value should be the language slug according to the /audio_languages endpoint
- speaker (STRING): Return talks which at least on of their speakers is the provided speaker, the provided value should be the speaker slug according to the /speakers endpoint
- publish_date (DATE (YYYY-MM-DD)): Return talks which were published on TED.com only on the exact provided date
- topic (STRING): Return talks which at least on of their topics is the provided topics, the provided value should be the speaker slug according to the /topics endpoint
- subtitle_lang (STRING): Return talks which have subtitles in the provided language, the provided value should be the language slug according to the /subtitle_languages endpoint
- max_duration (NUMBER): Return talks which their duration in seconds is at most the provided value
- to_publish_date (DATE (YYYY-MM-DD)): Return talks which were published on TED.com only before the provided date
- from_publish_date (DATE (YYYY-MM-DD)): Return talks which were published on TED.com only after the provided date
- min_duration (NUMBER): Return talks which their duration in seconds is at least the provided value
- record_date (DATE (YYYY-MM-DD)): Return talks which were recorded only in the exact provided date
- to_record_date (DATE (YYYY-MM-DD)): Return talks which were recorded only before the provided date
- from_record_date (DATE (YYYY-MM-DD)): Return talks which were recorded only after the provided date

### Random Words: Get a random word
Provider: Random Words — Random words api provides you a list of random words or a single random word
API: Get a random word
Description: Returns a random word from a comprehensive database of more than 35,000+ words. This endpoint provides access to the Random Words API's core functionality, allowing you to retrieve single random words from its extensive vocabulary collection. Note that when using this endpoint, the 'wordLength' parameter must not be used simultaneously with 'minLength' and/or 'maxLength' parameters to avoid conflicts in word selection criteria.
Required parameters: none
Optional parameters:
- beginsWith (STRING)
- minLength (NUMBER)
- endsWith (STRING)
- excludes (STRING)
- wordLength (NUMBER)
- includes (STRING)
- maxLength (NUMBER)
