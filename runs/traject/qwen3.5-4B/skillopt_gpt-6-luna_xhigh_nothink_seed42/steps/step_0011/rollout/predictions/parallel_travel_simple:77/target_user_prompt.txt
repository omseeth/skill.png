### Flight Info API: schedules
Provider: Flight Info API — Quickly look up flight information and get both future flight schedules and flight status data.
API: schedules
Description: Retrieves flight schedule information by specifying a mandatory Departure or Arrival Date, with optional parameters like Flight Number, Carrier Code, and airport codes. This tool quickly accesses comprehensive flight data, allowing you to look up both future flight schedules and current flight status information in one convenient service.
Required parameters: none
Optional parameters:
- After (STRING): A cursor after refers to a random string of characters which marks a specific item in a list of data.
- CodeType (STRING): Code type for Carriers and Airports. If not specified, carriers and airports are searched by IATA (default). Code type values are IATA, ICAO - for carriers and airports, FAA - for airports. Accepts comma separated values.
- CarrierCode (STRING): Carrier (airline) code assigned either by IATA or ICAO.
- ArrivalDateTime (STRING): Arrival date and/or time or date and/or time range is local time in ISO 8601 date format (e.g. YYYY-MM-DD[THH:MM] or YYYY-MM-DD[THH:MM]/YYYY-MM-DD[THH:MM]). The maximum date range is 31 days.
- ServiceType (STRING): Type of service: Passenger, Cargo. Only flights for the specified service type are returned if specified. Accepts comma separated values.
- AircraftRegistrationNumber (STRING): Aircraft registration number (Tail Number).
- FlightType (STRING): Type of flight: Scheduled, Unscheduled, General Aviation (GA). Accepts comma separated values.
- ArrivalAirport (STRING): A code assigned by the IATA/ICAO/FAA to an airport location representing arrival airport. If CodeType not specified, airports are searched by IATA (default). Accepts comma separated values.
- DepartureAirport (STRING): A code assigned by the IATA/ICAO/FAA to an airport location representing departure airport. If CodeType not specified, airports are searched by IATA (default). Accepts comma separated values.
- FlightNumber (NUMBER): A numeric part (up to four digits) of a flight designator.
- version (STRING): Api version.
- DepartureDateTime (STRING): Departure date and/or time or date and/or time range is local time in ISO 8601 date format (e.g. YYYY-MM-DD[THH:MM] or YYYY-MM-DD[THH:MM]/YYYY-MM-DD[THH:MM]). The maximum date range is 31 days.
