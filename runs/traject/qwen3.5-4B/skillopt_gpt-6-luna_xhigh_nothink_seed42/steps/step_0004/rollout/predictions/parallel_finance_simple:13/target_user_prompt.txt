### Bybit: Get Option Delivery Price
Provider: Bybit — Public Data Bybit. Cryptocurrency prices and charts. Derivatives, Futures, Spot, USDC Contract
API: Get Option Delivery Price
Description: Retrieves the delivery price for cryptocurrency options, specifically USDC contracts, by accessing real-time data from Bybit's public database. This endpoint leverages Bybit's comprehensive cryptocurrency price and charting services, which include derivatives, futures, and spot markets, to provide accurate and up-to-date pricing information for options delivery, enabling users to make informed trading decisions.
Required parameters: none
Optional parameters:
- direction (STRING): prev: prev, next: next.
- baseCoin (STRING): Base coin. Only valid when category=*option*. If not passed, BTC by default.
- category (STRING): Derivatives products category.For now, *linear inverse option* are available
- symbol (STRING): Symbol
- cursor (STRING): API pass-through
- limit (NUMBER): Limit for data size per page, max size is 200. Default as showing 50 pieces of data per page
