### Priceline com Provider: Downalods hotels
Provider: Priceline com Provider — priceline.com | Lets you search hotels, cars for rent, flights. **Support**: [tipsters@rapi.one](mailto:tipsters@rapi.one) / t.me/api_tipsters **Other travel api:** https://rapi.one
API: Downalods hotels
Description: Downloads a list of hotels based on user-specified criteria such as destination, dates, and preferences. This is part of Priceline.com's platform, which enables users to search for hotels, cars, and flights, leveraging a comprehensive database of travel options to provide accurate and up-to-date information for bookings. The endpoint integrates seamlessly with the broader service to streamline travel planning and reservation processes.
Required parameters: none
Optional parameters:
- active_mer (STRING): Show hotels with Priceline rates.
- latitude_range_end (STRING): Requires latitude to have value.
- active_smop (STRING): Show hotels with semi opaque rates.
- active_vmer (STRING): Show hotels with vacation merchant rates.
- state_code (STRING): Filter by the state code of the hotel.
- longitude_range_end (STRING): Requires longitude to have value.
- active_bkg (STRING): Show hotels with Booking rates.
- latitude (STRING): Filter by latitude of the hotel.
- hotelid_ppn (STRING): Filter by PPN hotel ID.
- longitude (STRING): Requires longitude to have value.
- property_type_ids (STRING): Filter by property type ids. See the Property Type Filter Guide for more detail.
- cityid_ppn (STRING): Filter by PPN city ID.
- hotel_address (STRING): Filter by address of hotel.
- resume_key (STRING): Resume results from given ID.
- language (STRING): Language code: en-US, es-ES, fr-FR, pt-BR
- limit (NUMBER): Limits the number of results from the response.
- active_agd (STRING): Show hotels with Agoda rates.
- country_code (STRING): Filter by the country code of the hotel.
- changes_since (STRING): Date/time to filter the hotels that have been updated on or after this date. This will discover the last_changed_date of hotels in inventory (inclusive of the selected date). Date should be in a valid ISO 8601: https://en.wikipedia.org/wiki/ISO_8601 (YYYY-MM-DDThh:mm:ss{UTC_Offset}) format.
