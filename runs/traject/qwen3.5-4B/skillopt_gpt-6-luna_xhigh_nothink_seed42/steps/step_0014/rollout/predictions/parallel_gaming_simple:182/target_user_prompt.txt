### OpenCritic API: General Search
Provider: OpenCritic API — An API for accessing video game and video game review data
API: General Search
Description: Searches for combinations of outlets, games, and authors using a string input. This API provides access to video game and review data, enabling efficient searches across these categories to help users quickly locate specific information about games, their publishers (outlets), and developers (authors).
