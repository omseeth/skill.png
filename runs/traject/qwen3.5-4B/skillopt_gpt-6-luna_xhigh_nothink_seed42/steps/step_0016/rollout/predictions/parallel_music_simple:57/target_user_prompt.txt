## Tools
### Spotify _v2: Get user Playlists
Provider: Spotify _v2 — Get Spotify Tracks & Playlist Details
API: Get user Playlists
Description: Fetches all public playlists belonging to a specific Spotify user. This endpoint allows you to access a user's collection of publicly available playlists from Spotify's extensive music library, enabling you to discover curated music collections created by that user. The data returned includes playlist details that can be used to further explore tracks, artists, and other music content within the Spotify ecosystem.
Required parameters:
- user_id (STRING)
Optional parameters: none

### SoundCloud Scraper: Search for Users
Provider: SoundCloud Scraper — An all-in-one SoundCloud scraper/downloader. Scrapes albums, playlists, profiles. Downloads uncut high-quality audios and lyrics.
API: Search for Users
Description: Searches for SoundCloud users with optional filters and pagination support, allowing you to find specific creators on the platform. This is part of a comprehensive SoundCloud scraper/downloader that enables you to access various content types including albums, playlists, and profiles, while also providing capabilities to download uncut high-quality audio files and lyrics from the platform.
Required parameters:
- term (STRING): Search term.
Optional parameters:
- offset (NUMBER): (**README**: [How to Use Endpoints with `offset`](https://rapidapi.com/DataFanatic/api/soundcloud-scraper/tutorials/how-to-use-endpoints-with-%60offset%60)) The number of items omitted before the results. Defaults to `0`.
- limit (NUMBER): The max number of items returned. Defaults to `50`.
- place (STRING): Filters by a user's location (e.g., `London`).
