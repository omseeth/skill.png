### Ali Express Data Service: Search Items
Provider: Ali Express Data Service — Our Ali Express commodity data API provides you with easy access to valuable product, and seller data from the popular e-commerce platform. Our endpoints are designed to provide you with fast, accurate data without the need to create a scraper or subscribe to the official Ali Express API. With easy-to-understand documentation, error handling, and response status codes, our API is built to help you make the most of your data. Choose from our flexible pricing plans to suit your needs and start ...
API: Search Items
Description: Searches for items using a query string. This endpoint leverages the Ali Express commodity data API to retrieve product and seller information from the e-commerce platform, enabling efficient data retrieval without requiring a scraper or official API subscription. It utilizes the API's structured database to deliver fast, accurate results tailored to user queries, enhancing accessibility to Ali Express's extensive product catalog and seller metrics through a streamlined, developer-friendly interface.
Required parameters:
- query (STRING): Search query
Optional parameters:
- sort (STRING): This parameter is used to specify the sorting order of the items returned in the API response. There are six available sorting options for the `sort` parameter: `default`: This is the default sort option, and it sorts the items based on the Pinduoduo platform's default sort order. `price_asc`: This option sorts the items in ascending order of their prices, with the lowest priced items appearing first in the response. `price_desc`: This option sorts the items in descending order of their prices, with the highest priced items appearing first in the response. `total_price_asc`: This option sorts the items in ascending order of their total prices, which includes any discounts or promotions, with the lowest total priced items appearing first in the response. `total_price_desc`: This option sorts the items in descending order of their total prices, with the highest total priced items appearing first in the response. `volume_desc`: This option sorts the items in descending order of their sales volume, with the best-selling items appearing first in the response. `vendor_rating_desc`: This option sorts the items in descending order of their seller rating, with the highest rated sellers appearing first in the response. `updated_time_desc`: This option sorts the items in descending order of their update time, with the most recently updated items appearing first in the response.
- inStock (BOOLEAN): If set to true, the results will contain only items in stock, if set to false the results will contain only items out of stock. Don't set the parameter so you can get both results.
- hasDiscount (BOOLEAN): If set to true, the results will contain only items with discount, if set to false the results will contain only items without a discount. Don't set the parameter so you can get both results.
- query_language (STRING): The `query_language` parameter specifies the language of the search query provided in the `query` parameter for translation into Chinese. This is important because the query must be in Chinese to be searched on the platform.
- minPrice (NUMBER): Minimum Item Price
- target_language (STRING): The language of translation, list of all supported languages can be found [here](https://rapidapi.com/iamEvara/api/ali-express-data-service/tutorials/list-of-all-supported-languages).
- maxPrice (NUMBER): Maximum Item Price
- page (NUMBER): The page number of the results to be retrieved. Default is 1.
- size (NUMBER): Number of results per page.

Then they browsed Asos categories in English for the US market. They looked up specific product information for an Amazon item (ASIN: B07QBRXSF1) on the US marketplace. The search continued on Aliexpress, where they performed two separate searches for ergonomic office chairs priced between $200-$500 in the US region. Finally, they focused back on Wayfair, reading customer reviews for a specific chair (SKU: W004939121), sorting by most helpful reviews, and then looking for products similar to another chair model (SKU: W003078383).
