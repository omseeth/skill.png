### Newscatcher: /v1/search_enterprise
Provider: Newscatcher — API to find news articles by any topic, country, language, website, or keyword
API: /v1/search_enterprise
Description: Performs a highly customizable search for news articles using filters and sorting options. This endpoint leverages the parent API's capability to retrieve articles by topic, country, language, website, or keyword, utilizing a comprehensive database to deliver precise and tailored results.
Required parameters:
- q (STRING): String to search for. Has to be [URL-encoded](https://en.wikipedia.org/wiki/Percent-encoding)
Optional parameters:
- link_begins_with (STRING): Filter on the prefix of the URL. For example: `https://www.nytimes.com/2020/12/25/business` will give you all the articles for the exact date for **business** subject. Be aware that every news website has its own structure. Use this parameter only if you want to be precise in your search. In all other cases, use parameters that we provide you for deep search like `topic`, `from`, `to` etc.
- sort_by (STRING): - `relevancy` — the most relevant results first, - `date` — the most recently published results first, - `rank` — the results from the highest-ranked sources first
- topic (STRING): The topic to which you want to restrict the articles of your choice. This parameter is [experimental]. Accepted values are `news`, `sport`, `tech`, `world`, `finance`, `politics`, `business`, `economics`, `entertainment`,`beauty`,`travel`,`music`,`food`,`science` `news` usually means a general news feed (main headlines of a website). > Important: this parameter is [experimental]. Not all news articles are assigned with a `topic`, therefore, we cannot guarantee that 100% of topics talking about technology will be assigned a `tech` label. > One topic at a time, for example `topic=sport`
- to (STRING): Until which point in time to search for. The default timezone is UTC
- to_rank (NUMBER): Upper boundary of the rank of news website to filter by
- from_rank (NUMBER): Lowest boundary of the rank of news website to filter by. **Important**: lower rank means that a source is more popular
- lang (STRING): Specifies the language of the search. Allowed values are: `af`, `ar`, `bg`, `bn`, `ca`,`cn`, `cs`, `cy`, `da`, `de`, `el`, `en`, `es`, `et`, `fa`, `fi`, `fr`, `gu`, `he`, `hi`, `hr`, `hu`, `id`, `it`, `ja`, `kn`, `ko`, `lt`, `lv`, `mk`, `ml`, `mr`, `ne`, `nl`, `no`, `pa`, `pl`, `pt`, `ro`, `ru`, `sk`, `sl`, `so`, `sq`, `sv`, `sw`, `ta`, `te`, `th`, `tl`, `tr`,`tw`, `uk`, `ur`, `vi`. Specifying the language will make your search more relevant
- page_size (NUMBER): How many articles to return per page. Defaults to 50, max is 100. Not included in Basic plan.
- ranked_only (STRING): Limit the search only for the sources which are in top 1 million online websites. Defaults to `True` (`False` if you want to turn it off). Unranked sources are assigned a rank that equals to `999999`
- sources (STRING): One or more news resources to filter your search. It should be the normal form of the URL, for example, **[nytimes.com](http://nytimes.com/)**, **[theguardian.com](http://theguardian.com/)** > Comma separated string, for example `sources=nytimes.com,cnn.com,wsj.com`
- search_in (STRING): By default, we search what you specified in `q` in both `title` and `summary` of the article. However, you can limit this to either `title` or `summary`
- media (STRING): Adds to the output of the call two more variables: `media` and `media_content` Media - the main image published with an article media_content - a comma-separated string of all images used in an article
- from (STRING): From which point in time to start the search. No specific format is required. E.g. (`2020/05/01`, `2020-05-01` ,`2020-05-01 12:54:14`, `2020-05-01 4:15am`, `yesterday 2:02 am`, `2020/05/01 12:55 EST`) . The default timezone is UTC. **Defaults to one week ago at midnight UTC.**
- country (STRING): The country to which you want to narrow your search. This parameter is [experimental]. We advise you to use it in conjunction with the `lang` parameter. Accepts any [ISO 3166-1 alpha-2](https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2) codes
- not_sources (STRING): One or more sources to be excluded from the search. > Comma separated string, for example `not_sources=nytimes.com,cnn.com,wsj.com`
- page (NUMBER): The number of the page. Use it to scroll through the results. Defaults to 1
