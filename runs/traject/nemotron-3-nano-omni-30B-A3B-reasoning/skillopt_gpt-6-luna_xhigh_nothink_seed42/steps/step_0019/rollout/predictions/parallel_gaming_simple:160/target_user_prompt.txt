## Tools
### Epic Games Store - Free Games: Free Games
Provider: Epic Games Store - Free Games — Unofficial API for scraping Free Games Offers from the Epic Games Store
API: Free Games
Description: Retrieves all currently available and upcoming free games from the Epic Games Store, including details about each title and its availability period. This endpoint leverages an unofficial API designed for scraping game offer data, utilizing web scraping techniques to extract real-time information from the Epic Games Store's frontend, providing developers and users with a convenient way to track free game promotions without direct access to Epic's official systems.
Required parameters: none
Optional parameters:
- country (STRING): Country Code for local offers. E.g, ES, DE, US. Defaults to US

### OpenCritic API: Game Search
Provider: OpenCritic API — An API for accessing video game and video game review data
API: Game Search
Description: Searches OpenCritic for games with similar names/titles using inverse trigram distance, where 0 represents a perfect match and 1 indicates no shared trigrams. This endpoint leverages the pg_trgm library for efficient text similarity calculations, enabling precise game discovery by analyzing title patterns. As part of an API for video game and review data, it enhances user experience by surfacing relevant game recommendations through advanced text matching algorithms.
Required parameters:
- criteria (STRING)
Optional parameters: none
