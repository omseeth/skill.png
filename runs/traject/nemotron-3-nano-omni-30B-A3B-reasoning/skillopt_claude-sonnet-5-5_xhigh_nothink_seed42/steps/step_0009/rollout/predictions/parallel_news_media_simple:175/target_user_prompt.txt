### Newscatcher: /v1/search_free
Provider: Newscatcher — API to find news articles by any topic, country, language, website, or keyword
API: /v1/search_free
Description: Retrieves up to 100 news articles per API call using parameters like topic, country, language, website, or keyword, with free plans limited to language filters. This endpoint leverages the broader news search API's capability to access a diverse dataset of articles, enabling efficient information gathering and customization through targeted queries.
Required parameters:
- q (STRING): String to search for. Has to be [URL-encoded](https://en.wikipedia.org/wiki/Percent-encoding)
Optional parameters:
- media (STRING): Adds to the output of the call two more variables: `media` and `media_content` Media - the main image published with an article media_content - a comma-separated string of all images used in an article
- page (STRING): The number of the page. Use it to scroll through the results. Defaults to 1
- ranked_only (STRING): Limit the search only for the sources which are in top 1 million online websites. Defaults to `True` (`False` if you want to turn it off). Unranked sources are assigned a rank that equals to `999999`
- page_size (STRING): How many articles to return per page. Defaults to 50, max is 100
- lang (STRING): Specifies the language of the search. Allowed values are: `af`, `ar`, `bg`, `bn`, `ca`,`cn`, `cs`, `cy`, `da`, `de`, `el`, `en`, `es`, `et`, `fa`, `fi`, `fr`, `gu`, `he`, `hi`, `hr`, `hu`, `id`, `it`, `ja`, `kn`, `ko`, `lt`, `lv`, `mk`, `ml`, `mr`, `ne`, `nl`, `no`, `pa`, `pl`, `pt`, `ro`, `ru`, `sk`, `sl`, `so`, `sq`, `sv`, `sw`, `ta`, `te`, `th`, `tl`, `tr`,`tw`, `uk`, `ur`, `vi`. Specifying the language will make your search more relevant
