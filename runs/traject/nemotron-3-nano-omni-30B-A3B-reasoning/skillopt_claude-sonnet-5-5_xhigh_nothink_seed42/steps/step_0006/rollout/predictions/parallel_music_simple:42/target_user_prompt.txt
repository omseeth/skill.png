### Genius - Song Lyrics: Videos
Provider: Genius - Song Lyrics — Genius - Song Lyrics, Artists, Albums, Knowledge & More API
API: Videos
Description: Retrieves music videos associated with songs, artists, or albums. This endpoint is part of the Genius API, which provides comprehensive access to a vast database of song lyrics, artist information, album details, and music knowledge. The API allows users to explore rich content about music, including factual information, interpretations, and media related to songs and artists, making it a valuable resource for music enthusiasts, researchers, and developers building music-related applications.
Required parameters: none
Optional parameters:
- per_page (NUMBER): Number of results to return per request
- text_format (STRING): Format for text bodies related to the document. One or more of `dom`, `plain`, `markdown`, and `html`, separated by commas (defaults to html).
- page (NUMBER): Paginated offset, (e.g., per_page=5&page=3 returns albums 11–15)
- artist_id (STRING): Artist ID
