### Target.Com(Store) Product/Reviews/Locations Data: Product Search
Provider: Target.Com(Store) Product/Reviews/Locations Data — Real-time **Target.Com** data API. Get product, reviews and location details. Easy to use and reliable I'm on Telegram https://t.me/logicBuilder News and announcements Telegram Channel https://t.me/logicApi
API: Product Search
Description: Returns product search results from Target.com based on search queries. This endpoint leverages real-time Target.com data to deliver accurate and up-to-date product information, requiring a store_id parameter which can be obtained using the /target/location/search endpoint. The API provides reliable access to Target's extensive product catalog, reviews, and location details, allowing for seamless integration of Target's retail data into applications and services. Part of a comprehensive Target data solution that prioritizes ease of use and data reliability.
Required parameters:
- store_id (NUMBER): Store id - Every target has a uniq **store_id** , **store_id** can be extract with the help of this endpoint **/target/location/search**
- keyword (STRING): Search keyword For example: **iphone case**
Optional parameters:
- limit (NUMBER): Limit the output number of records. - Default is 24 - Max number is 24
- offset (NUMBER): Skin ~~n~~ amount of records Default: 0
- rating (NUMBER): To show only products with the rating for example >=4 you can set query value to 4 . It can be 1,2,3,4,5
- sponsored (NUMBER): Should sponsored products be included in the result
- sort_by (STRING): You can sort products by using this query: - Relevance: **relevance** - Featured: **featured** - Price low to high: **pricelow** - Price high to low: **pricehigh** - Best selling: **bestselling** - Newest products: **newest** For example if you need to sort search by \\\"Price low to high\\\" then you would need to set query value to **pricelow**
